📡 DR Radar · Alertas 24/7

Web Push para recibir alertas aunque cierres el navegador.

Activa DR Radar en este dispositivo

Las alertas se envían mediante Web Push estándar. El sistema de detección de DR Radar continúa separado e independiente.

📱 iPhone / iPad
  1. En Safari toca Compartir.
  2. Elige Añadir a pantalla de inicio.
  3. Abre DR Radar desde el nuevo icono.
  4. Dentro de la app web pulsa Activar alertas 24/7.
📲 Instalar DR Radar

Puedes instalar esta web como aplicación para tener acceso directo a las alertas.

Comprobando este dispositivo…

DR Radar consulta los feeds cada 30 segundos desde un servicio independiente y envía únicamente alertas nuevas. La alerta que ya estaba activa al iniciar el servicio se usa como referencia y no se reenvía.
